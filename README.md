# 🤖 ShivMind
A MERN-based AI Chat Application

## 📖 Project Summary
SigmaGPT is a full-stack AI chat application built using the MERN stack.  
It works like a ChatGPT-style platform where users interact with an AI model powered by the OpenAI API.

The system supports user authentication, chat history storage and a smooth real-time chat interface.  
This project demonstrates how to build a complete AI chat system using modern web technologies.

---

## 🌐 Front-end

**Technologies Used:** React.js, HTML, CSS, JavaScript

### Features
- 💬 Real-time chat interface with smooth message flow  
- 📱 Responsive UI for all devices  
- 🔔 Typing indicators and clean layout  
- 🎨 Simple and intuitive design  
- 🔄 Auto-scroll for seamless message experience  

---

## 🛠️ Back-end

**Technologies Used:** Node.js, Express.js

### Features
- 🔗 RESTful API to send prompts and receive AI responses  
- 🔐 User Authentication (JWT or OAuth – optional)  
- ⚡ Efficient logic for real-time requests  
- 🧩 Modular server structure  
- 🔄 Chat history storage and retrieval  

---

## 🧠 AI Integration

**Provider:** OpenAI API

### Features
- ⚙️ Connects with OpenAI models to generate replies
